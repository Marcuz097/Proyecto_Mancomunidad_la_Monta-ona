# 🌿 Fortalecimiento Institucional - Mancomunidad La Montañona

Plataforma web integral desarrollada en **C# (ASP.NET Core)** y **Entity Framework Core** para el fortalecimiento institucional, transparencia y gestión operativa de la **Mancomunidad La Montañona** (*"Hábitat para comunidad"*).

El sistema moderniza la presencia digital de la institución (proyectado para `LaMontañona.gob.sv`) tomando como referencia los estándares de claridad e información ciudadana del Ministerio de Medio Ambiente y Recursos Naturales (MARN).

---

## 🎯 Objetivos del Proyecto

1. **Sitio Web Institucional:** Difundir los 25 años de trayectoria sostenible de la mancomunidad, sus ejes estratégicos, convenios (ej. ACACYPAC) y el programa *Somos Río Lempa*.
2. **Registro Único de Participantes:** Centralizar en una base de datos relacional sólida a los beneficiarios de los distintos programas sin duplicidad de registros.
3. **Sistema de Reporte Unificado y Operativo:** Facilitar el monitoreo ambiental mediante denuncias ciudadanas con evidencia fotográfica y reportes estandarizados de guardabosques.

---

## 🚀 Módulos y Características Principales

### 🌐 Portal Público
* **Ventana Multimedia "Somos Río Lempa":** Reproducción continua de material audiovisual informativo del programa.
* **El Observatorio Informa:** Módulo de monitoreo con el *Pronóstico oficial 48 horas* y alertas ambientales.
* **Plan de Trabajo (5 Ejes Estratégicos):**
  1. Protección y conservación del bosque y biodiversidad.
  2. Restauración y producción sostenible (énfasis en *Sistemas agropastoriles* para generación de ingresos familiares).
  3. Gobernanza para la gestión hídrica.
  4. Fortalecimiento institucional.
  5. Desarrollo económico local / Turismo.
* **Canales de Atención y Denuncia:** Integración directa con líneas telefónicas, WhatsApp y correos institucionales de salvaguardia.

### 📊 Gestión de Datos y Reportes
* **Registro Único de Beneficiarios:** Validación de identidad única para cruzar la participación de personas y familias a través de múltiples programas.
* **Mecanismo de Denuncias e Incidentes:** Formulario web responsivo que permite a la ciudadanía reportar incidentes ambientales y adjuntar fotografías en tiempo real.
* **Portal de Guardabosques:** Módulo dedicado para garantizar el envío periódico y estandarizado de reportes de patrullaje.
* **Generador de Reporte Unificado:** Consolidación automática de indicadores de participantes, programas e incidentes para la toma de decisiones.

## 🛠️ Stack Tecnológico

* **Backend:** C# / ASP.NET Core MVC
* **ORM:** Entity Framework Core (Code First)
* **Base de Datos:** SQL Server
* **Frontend:** Razor Views, HTML5, CSS3, Bootstrap / Tailwind CSS, JavaScript
